# CMS — Strapi v5

Strapi v5 headless CMS for the Akash Borkar portfolio. Hosted on Render Free with Neon PostgreSQL.

See the [root README](../README.md) for setup instructions, environment variables, and the CMS schema change workflow (pre-building `cms/dist/` locally before every push).

## Commands

```bash
npm run develop   # Start Strapi at http://localhost:1337
npm run build     # Build admin panel (run locally before pushing — see root README)
npm run start     # Start without autoReload (production)
```

## Admin

- Local: http://localhost:1337/admin
- Production: https://strapi-cms-2usx.onrender.com/admin
